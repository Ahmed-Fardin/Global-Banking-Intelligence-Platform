

The SQL analysis layer is designed to answer business and financial
questions about banks, countries, profitability, growth, risk, and
financial performance from 2020 to 2025.

The SQL analysis uses the PostgreSQL `bank_financials` table and
related reference tables.

# Important Analytical Limitation

The original financial dataset contains monetary values in the
reporting currency of each bank.

Therefore, local-currency monetary values must not be used for direct
global bank-size comparisons.

The separate USD-normalized dataset should be used when comparing
monetary values across countries and currencies.

Ratios such as ROE, ROA, capital adequacy, cost-to-income,
loan-to-deposit, and NPL ratio are already expressed as ratios or
percentages and do not require currency conversion.
